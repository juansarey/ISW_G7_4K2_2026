# Ingenieria y Calidad de Software - 2026

Repositorio para los productos de la materia Ingenieria y Calidad de Software.

La estructura, los Items de Configuracion, las reglas de nombrado y el criterio de lineas base se definen en [`00-SCM/`](00-SCM/).

## Estructura principal

- `00-SCM/`: documentacion de Gestion de Configuracion.
- `01-reglas-materia/`: normas, criterios e indicaciones de la catedra.
- `02-material-teorico/`: bibliografia, presentaciones y material de referencia.
- `03-trabajos-practicos/`: productos de los trabajos practicos.
- `04-trabajo-investigacion-grupal/`: productos del trabajo de investigacion grupal.

Los nombres estables de los archivos, sin versiones en el nombre, y la evolucion mediante Git son obligatorios. Consultar las reglas SCM antes de agregar contenido.
